## Project

Skyglass is a native Android stargazing app (Kotlin, Jetpack Compose, OpenGL ES 3.0). Point the phone at the sky and it draws what is there, using the rotation vector sensor, location, time and magnetic declination.

Built: naked-eye stars (Yale Bright Star Catalogue, V ≤ 6.5), constellation lines, names and details cards (myth, brightest stars, chart), constellation artwork (Stellarium's illustrations), Sun, Moon (with phase) and planets, ~175 deep-sky objects, a procedural Milky Way band, horizon line, compass letters and alt-az grid, tap-to-identify with details cards (position, rise/set, etc.; photos of deep-sky objects, the Sun, Moon and planets, and a gallery of the planets' major moons), search with on-screen guidance, a faintest-stars slider, and a camera view that draws the sky over the live rear-camera image.

Not built: zoom, night (red) mode, planetary moons, asteroids/comets, daylight sky, constellation boundaries.

## Commands

Run from the repo root (`./gradlew` in Git Bash, `.\gradlew.bat` in PowerShell).

- Build debug APK: `./gradlew assembleDebug`
- Unit tests (JVM, `app/src/test`): `./gradlew test`
- Single test class/method: `./gradlew testDebugUnitTest --tests "com.skyglass.astro.CoordinatesTest"` (the aggregate `test` task does not accept `--tests`)
- Instrumented tests (needs a device): `./gradlew connectedAndroidTest`
- Lint: `./gradlew lint`
- Install: `./gradlew installDebug`

The configuration cache is enabled, and the daemon JVM toolchain is pinned to 25 (`gradle/gradle-daemon-jvm.properties`).

## Architecture

- Single module `app` (`com.skyglass`), `minSdk` 28, `compileSdk`/`targetSdk` 37. Add dependencies through the version catalogue (`gradle/libs.versions.toml`, `libs.*`), never inline. No Play Services and no INTERNET permission: all data is bundled in `app/src/main/assets/`.
- **Rendering.** Every sky object is a unit vector in the mean equatorial frame of date (stars: proper motion + IAU 1976 precession, once at load), uploaded to a VBO. Each frame the GPU applies one MVP from `render/SkyViewMath`:
  `clip = P · S(displayRotation) · R(q)ᵀ · M(true→magnetic) · H(LST, lat) · v_eq`.
  Horizon geometry is in true ENU and uses the same chain without `H`. No nutation or aberration anywhere, so everything stays in step.
- **Draw order:** Milky Way, constellation art (+ highlighted constellation's), horizon guides, constellation lines (+ highlighted constellation), deep-sky objects, stars, then Sun/Moon/planets (`SkyBody` enum order; Moon last).
- **Two views.** Enhanced: additive blending onto opaque black. Camera: GL surface is translucent over a CameraX preview; shaders take `uCameraMode` and output `alpha = max(r, g, b)` with premultiplied "over" blending (`render/OverlayBlend`). Any new shader must follow this rule.
- **Threading.** `SkyRenderer` runs on the GL thread; values cross from the main thread through `@Volatile` fields in `SkyRenderInputs` (arrays are replaced wholesale, never mutated). Sensor callbacks and `HeadingFusion` run on the main thread. Taps, labels and guidance project on the CPU with the last frame's `lastMvp` / `lastHorizonMvp`.
- **Orientation:** TYPE_ROTATION_VECTOR fused with TYPE_GAME_ROTATION_VECTOR (`sensors/HeadingFusion`): motion from the gyroscope, heading from the magnetometer through a 2 s low-pass, so magnetometer jumps become glides.
- **Packages:**
  - `math/`, `astro/`, `catalog/` (except `StarCatalog`), `render/` (except `SkyRenderer` and `ShaderProgram`; shaders are plain GLSL strings), `sensors/OrientationFilter` and `HeadingFusion`, and `ui/CameraStateTracker`: **pure Kotlin, no Android calls**, covered by JVM tests. Keep new math there.
  - `sensors/`: Android sensor, location (`LocationManager`) and `GeomagneticField` wrappers.
  - `render/SkyRenderer`: the GL thread; `ShaderProgram` compiles shaders.
  - `ui/`: `SkyViewModel` (state, catalogue load, body updates every 10 s, selection, rise/set on `Dispatchers.Default`), `SkyScreen` (permissions, GL view, toggles, Display card), `SkyOverlay` (Compose labels, rings, arrows), `ObjectInfoCards`, `NavigationUi`, `CameraPreviewLayer`.
- **Data files** (`app/src/main/assets/`): `bsc5.dat` (unmodified CDS V/50, fixed-width; `BscParser` pads trimmed lines), `deep_sky.txt`, `constellation_lore.txt` and `constellation_art.txt` (formats documented in each file's header), the illustrations in `constellation_art/` (Free Art License; `constellation_art.txt` and the PNGs are generated by `tools/constellation_art/gen_art.py`), and the photos in `object_images/` with their index `object_images.txt` (NASA public domain or CC BY 4.0; generated by `tools/object_images/gen_images.py` from the hand-curated `sources.src`, which needs Pillow; the figure and star-name files by `tools/constellations/gen_assets.py`; never edit generated files by hand). Check licences before adding data; see the provenance notes in the design notes.
- Visual tuning lives in the `*Appearance` objects in `catalog/`. User-visible text goes in `strings.xml` (star names and constellation lore are English-only assets).
- Settings persist in SharedPreferences `display_settings`. The activity is locked to portrait, but Android 16+ ignores that on large screens (`SkyViewMath.deviceToScreen` handles all four rotations).

## Frame conventions

Pinned by unit tests; sign errors are the main risk when changing this code.

- Equatorial: +X vernal equinox, +Z north celestial pole.
- ENU: +X east, +Y north, +Z up. The rotation vector's world frame uses *magnetic* north; `Coordinates.magneticToTrueEnu` corrects it (declination positive east).
- Device (portrait) = GL eye frame: +X right, +Y up, +Z out of the screen; the camera looks down −Z.
- Azimuth from north through east (Meeus measures from south).
- Ephemeris time is UTC + 69.184 s (`AstroTime.julianEphemerisDay`).

## Tests

JVM tests in `app/src/test` cover the math, catalogues, hit testing, search, navigation and blending. Use independently sourced expected values (Meeus, *Astronomical Algorithms*, worked examples; US Naval Observatory data), never the implementation's own output. Test all four display rotations for anything that projects to the screen. `app/src/androidTest` covers asset loading and `GeomagneticField`'s sign convention.
